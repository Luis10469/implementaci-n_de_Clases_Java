# Proyecto Product

Este proyecto fue desarrollado en Java y tiene como objetivo demostrar el uso de:

- Clases
- Atributos
- Constructores
- Métodos Getter y Setter
- Método toString()

## Cómo ejecutar el proyecto

1. Compilar los archivos:

```bash
javac src/main/java/com/example/*.java
```

2. Ejecutar el programa:

```bash
java com.example.Main
```

## Ejemplo de salida

```text
Nombre del producto 1: Mouse
Precio del producto 2: 2400.0
Producto [ID: P001, Nombre: Mouse, Precio: 50.0, Stock: 20]
Producto [ID: P123, Nombre: Laptop, Precio: 2400.0, Stock: 10]
```
